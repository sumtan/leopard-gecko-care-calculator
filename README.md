# Leopard Gecko Care Calculators
A simple reference for leopard gecko heating setup following the 1/3 heat mat rule.

## The 1/3 Heat Mat Rule
For leopard geckos, the warm side of the enclosure should cover roughly **1/3 of the floor space**. This creates a proper thermal gradient so the gecko can choose its preferred temperature.

### Formula
> Required heat mat width ≈ Enclosure floor width × 0.33
>
> The heat mat should not cover the whole tank, and must be regulated with a thermostat.
